# Learn AI Agentic Coding

This is the student starter repo for the [Learn AI Agentic Coding](https://codeling.dev/courses/learn-ai-agentic-coding/) course provided by [Codeling](https://codeling.dev).

## How to use this repo

To use this repo you need to create a copy of it in your own GitHub account and then clone it to your local computer.

Follow these steps:

1. Create your own copy of this repo:
   - Follow this link: [Create repo from template](https://github.com/new?template_name=course_learn_ai_coding_init&template_owner=codelingdotdev)
   - Or click _Use this template_ > _Create new repository_ button on this screen
2. Give the repository a name (eg: learn-ai-agentic-coding)
3. Tick **Include all branches**. Later lessons use extra branches from this repo.
4. Click the _Create Repository_ button
   - This will create a copy of this repo in your account
5. Clone your repo onto your local computer
6. Start the course here: [https://app.codeling.dev](https://app.codeling.dev)

Your course progress will sync to your Codeling account automatically.

## What you'll need

- The Codeling CLI and `uv`. The first lesson walks you through installing both.
- An AI coding agent. You'll install one early in the course.
